# היתכנות ותקציב בנייה: גרסת מאפיינים 3

גרסה 3 כוללת 264 מאפייני קלט: 228 המאפיינים של גרסה 2 באותו סדר ועוד 36 מאפייני היתכנות בנייה. גרסאות 1 ו־2 נשארות זמינות ללא שינוי בסדר העמודות.

לכל דרך, יישוב, עיר וקלף פיתוח נוספו מספר הרכישות שאפשר לממן מהיד הנוכחית ומגבלה לפי חלקים פנויים. לעיר נבדק גם מספר היישובים שאפשר לשדרג. התכונות מופיעות גם אחרי העלויות והרווחים הידועים של המהלך המוצע. שדרוג עיר מחזיר חלק של יישוב למלאי. יכולת לממן אינה מבטיחה מקום חוקי, ולכן קיימים בנפרד מספר המהלכים החוקיים והדגל `can_build_now` לפי רשימת הפעולות החוקיות הנוכחית.

למשל, שתי יחידות עץ ושתי יחידות לבנים מספיקות לשתי דרכים מבחינת משאבים. אם נשאר רק חלק דרך אחד, הקיבולת מוגבלת לאחת. `own_two_road_sequence_feasible` דורש גם שלב שמאפשר שתי הצבות רצופות, פעולה ראשונה חוקית ואפשרות גאומטרית להציב דרך שנייה אחרי הוספת הקשת הראשונה. הבדיקה מתבצעת בגרף הציבורי בלבד, ללא קריאה לסימולטור. בשלב ההקמה לא מסמנים רצף כזה כאפשרי.

בנוסף נוספו תקציבים משותפים: דרך ויישוב, ושתי דרכים ויישוב. הם משתמשים בסכום העלויות ולא סופרים אותם משאבים פעמיים. שתי דרכים ויישוב דורשים בדרך כלל שלוש יחידות עץ, שלוש לבנים, צמר וחיטה, וגם חלקים פנויים. דרכים חינמיות פעילות מפחיתות את עלות המשאבים; אפשרות לשחק קלף בניית דרכים מופיעה בנפרד מהקרדיט הפעיל.

תחזיות אחרי המהלך משתמשות רק בעלויות ורווחים ידועים. הן אינן מניחות תוצאת קוביות, משאב שנגנב, רווח מונופול לא ידוע או חילופי משאבים עתידיים. תקציב משותף אינו אישור שכל רצף המבנים יהיה חוקי; סימון היתכנות גאומטרית של רצף נעשה כרגע רק עבור שתי דרכים.

הייצוא נמצא ב־`runs/regression-build-capacity-v3`: 13,924 שורות, מתוכן 11,260 אימון, 1,396 אימות ו־1,268 בדיקה. מקורו ב־100 משחקים שכבר נאספו; התוויות נשארו כפי שהיו והנרמול מותאם רק לקבוצת האימון.

```powershell
.venv\Scripts\python.exe -m catanzero.regression_data runs/dataset-pilot-100-v2 --feature-version v3 --output runs/new-build-capacity-export
```

בפיילוט SARSA החדש נשמר הנרמול הישן ל־164 המאפיינים הראשונים; רק המאפיינים הנוספים משתמשים בנרמול מהייצוא הזה. המודל מתחיל ממשקולות הלינארי הקיים ומאפס משקולות התוספות, ואז מקבל עדכונים ממשחקים חדשים ללא חיפוש קדימה.
